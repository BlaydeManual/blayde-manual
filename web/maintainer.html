Advanced: speed

Indexing runs single-threaded (Normal) by default, deliberately: a real run at a higher setting once locked up a real machine hard enough to need a power-cycle. Faster settings use more of this device's CPU at once (more workers, more speed, more load), capped well below what caused that. Adjustable while paused or before starting; greyed out while actively running.
